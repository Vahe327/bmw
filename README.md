# BMW_Lottery — TonConnect manifest

This repository hosts the TonConnect manifest for the **BMW_Lottery** Telegram mini-app on TON.

TonConnect requires the manifest to be served from a public, stable URL so that wallets (Tonkeeper, Tonhub and others) can read the app name, icon and return URL before approving a connection. GitHub Pages / raw hosting is used for exactly that.

- `bmw.txt` — the manifest served to wallets
- App endpoint: `bot.bmw-ton.io`

> ⚠️ This manifest is live — the running app depends on it. Please don't rename or delete the file.
